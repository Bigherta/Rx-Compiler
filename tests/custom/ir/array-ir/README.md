# 数组构造与下标表达式 IR 测试

```sh
make test FILTER=custom:ir:array-ir
```

精选 20 项，覆盖：

- 空数组、列表/重复构造、嵌套、动态元素及整数/bool 元素。
- 4096 元素重复初始化、只求值一次、零长度副作用、引用/结构体元素。
- 常量/动态下标、临时数组、函数返回、共享/可变/多层引用。
- 可变引用、临时元素借用及多维数组修改。
- 求值顺序、下标修改原数组、提前返回。

聚合结果由 Rx 入口逐元素输出，预期值来自原回归脚本。
不再断言 GEP/insertvalue 数量或整数组加载形式。
运行流程、日志及迁移边界见[上级说明](../README.md)。
