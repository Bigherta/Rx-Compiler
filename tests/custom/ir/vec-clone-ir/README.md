# Vec::clone IR 测试

```sh
make test FILTER=custom:ir:vec-clone-ir
```

精选 10 项，覆盖：

- 空 Vec、u32 边界、bool 数组和有填充的结构体。
- Box、含 Box 的结构体、嵌套 Vec、递归 Node 及共享/多层引用。
- 修改克隆结果的非引用标量叶子后，原值保持不变（引用接收者用例）。
- 接收者只求值一次，以及同名固有方法不替代内建 Clone。

输入改由 Rx 的 `new/push` 构造；原容量相关名称仅用于追溯。
不再强制构造指定容量，或直接断言指针身份、描述符、分配计数和哨兵。
遗留 `runtime.c` 不参与当前清单执行。
运行流程、日志及迁移边界见[上级说明](../README.md)。
