# 结构体构造与字段访问 IR 测试

```sh
make test FILTER=custom:ir:struct-expr-ir
```

精选 10 项，覆盖：

- 乱序初始化、非字母序字段、bool 填充、嵌套及数组字段。
- 初始化求值顺序与提前返回；字段读写、复合赋值、共享/可变借用。
- 存储的可变引用、临时字段借用、整字段赋值及传参独立性。
- 基表达式只求值一次、结构体数组与字段访问链。

聚合结果由 Rx 入口逐字段输出。不再直接匹配 GEP 编号、insertvalue 顺序，
也不限制整结构体加载形式。
运行流程、日志及迁移边界见[上级说明](../README.md)。
